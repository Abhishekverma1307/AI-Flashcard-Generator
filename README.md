# 📚 AI Flashcard Generator

An AI-powered Flashcard Generator built with **Python** and **Hugging Face**.

This project takes study material from the user and uses a Hugging Face AI model to automatically generate useful **Questions and Answers** in the form of flashcards.

---

## 🚀 Features

- 🤖 Uses Hugging Face AI
- 📚 Generates flashcards from study material
- ❓ Automatically creates questions
- ✅ Generates short answers
- 🔐 Uses `.env` to securely store the Hugging Face API token
- 🐍 Built completely with Python
- ⚡ Simple and beginner-friendly

---

## 🛠️ Technologies Used

- Python
- Hugging Face
- Hugging Face InferenceClient
- python-dotenv
- Google FLAN-T5 Base
